# Webp

웹 프로그래밍 수업 실습 저장소입니다. HTML5 · CSS3 · JavaScript 수업 내용과 과제(실습문제, Open Challenge)를 날짜별 폴더로 정리했습니다.

## 폴더 구조

```
Webp/
├── MMDD/                    # 수업 날짜 (예: 0909 = 9월 9일)
│   ├── chapN/               # 수업 시간 예제
│   └── report/
│       ├── practice_problem/  # 실습문제 (numN.html)
│       └── open_challenge/    # Open Challenge 과제
└── README.md
```
